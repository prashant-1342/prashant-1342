### Featured Projects

**[CodeStory – AI GitHub Activity Analyzer](https://prashantpal.vercel.app/)**
`Next.js` `TypeScript` `Groq AI` `Supabase` `GitHub OAuth`
- AI-powered dashboard that analyzes GitHub commit history and generates plain-English changelogs, coding-personality insights, and activity breakdowns across repositories
- Integrated GitHub OAuth via NextAuth to securely fetch commit data, diffs, and file-level stats using the GitHub REST API
- AI-generated changelogs powered by Groq's LPU inference engine (LLaMA 3.3) for near-instant, low-latency summaries, with Supabase caching to avoid redundant API calls and reduce costs
- Features include peak coding-hours analysis, code churn detection, most-changed-files ranking, and per-repository lines-added/deleted statistics

**[SafePad – Secure Password Manager](https://prashantpal.vercel.app/)**
`Next.js` `Supabase (PostgreSQL)` `AES Encryption`
- Engineered a zero-knowledge, AES-encrypted architecture with keys derived and held exclusively on-device, so the server and database never access plaintext secrets
- Enforced strict per-user data isolation and defense against unauthorized access using PostgreSQL row-level security (RLS) policies on Supabase
- Optimized frontend performance to a 94 Lighthouse score (0.4s FCP, 0.5s LCP, zero CLS), with 98 Accessibility and 100 Best Practices & SEO through semantic HTML and secure configurations
